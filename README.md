# Studio Arama

Website for Studio Arama — a design agency.

Built with **Next.js + TypeScript + Tailwind CSS**.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

```
src/
  app/            routes (home, work, services, about, contact)
  components/     shared UI (Header, Footer, ...)
  lib/            site config + utilities (site.ts)
  content/        project content
public/           static assets (images, etc.)
```
